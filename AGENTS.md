# Working on the React assignments

- Read `spec.md` before editing an example. The three examples are `src/Assignment1.jsx`, `src/Assignment2.jsx`, and `src/Assignment3.jsx`. Keep exercise state local when only one component owns it.
- Run `npm ci`, `npm run lint`, and `npm run build`. Use `npm run dev` to verify all three screens.
- Keep the React Router basename aligned with the Vite base path. Update `src/assignment3.txt` for changes to the written explanation.
